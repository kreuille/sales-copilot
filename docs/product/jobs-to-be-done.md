# Jobs-to-be-done

Repris et reformulés depuis les 10 fonctions du PDF (PART 2), un JTBD par fonction, avec les agents associés.

| # | Fonction (source PDF) | Job-to-be-done | Agents (prompts) |
|---|---|---|---|
| F1 | Prospection et recherche de signaux | "Quand je dois choisir qui contacter, je veux savoir qui est chaud MAINTENANT pour ne pas perdre de temps sur les mauvais comptes." | Agent 1 (Chasseur de Signaux), Agent 2 (Profileur) |
| F2 | Outreach et messaging personnalisé | "Quand je dois écrire un premier message, je veux une accroche qui obtient une réponse, pas un pitch ignoré." | Agent 3 (Accrocheur), Agent 4 (Architecte de Séquence) |
| F3 | Follow-up et relances | "Quand un prospect ne répond plus, je veux savoir quoi écrire et quand, sans culpabiliser ni harceler." | Agent 5 (Relanceur), Agent 6 (Réanimateur) |
| F4 | Qualification des deals | "Quand je sors d'un call, je veux une évaluation froide du deal pour ne pas perdre 3 semaines sur un mauvais prospect." | Agent 7 (Qualificateur), Agent 8 (Détecteur de Red Flags) |
| F5 | Gestion du pipeline | "Quand je regarde mon pipe, je veux savoir où est le vrai blocage et quoi faire cette semaine." | Agent 9 (Analyste de Pipeline), Agent 10 (Priorisateur) |
| F6 | Traitement des objections | "Quand un prospect objecte, je veux répondre sans être défensif et sans perdre la conversation." | Agent 11 (Désamorceur), Agent 12 (Sparring Partner) |
| F7 | Préparation des démos | "Quand je prépare une démo ou débriefe un call, je veux parler de SON problème, pas de mon produit." | Agent 13 (Préparateur de Démo), Agent 14 (Débriefeur de Call) |

| F9 | CRM et ops | "Quand j'ai des notes en vrac, je veux une fiche CRM propre et un compte rendu envoyable en 5 minutes." | Agent 17 (Greffier), Agent 18 (Rédacteur de Compte Rendu) |
| F10 | Suivi de performance | "Quand je regarde ma semaine, je veux savoir où mon funnel fuit et quelle UNE chose améliorer." | Agent 19 (Analyste de Perf), Agent 20 (Coach de Rétro) |
